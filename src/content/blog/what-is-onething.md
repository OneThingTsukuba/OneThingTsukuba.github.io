「エンジニアコミュニティ」と聞くと、情報学群の人が集まる場所を思い浮かべる人が多い。

OneThing は少し違う。代表は社会工学類の学生です。情報系以外の学類から来ているメンバーもいます。

## コードが書けること自体は、もう強みになりにくい

AI にコードを書かせるのが当たり前になりました。プロトタイプを作るだけなら、以前より圧倒的に速い。技術そのものの参入障壁は、この数年で大きく下がった。

じゃあ何が残るのか。

**「何を作るべきか」を決める力**と、**それを最後まで動く形にする力**。この2つだと考えています。

前者は自分の専門から出てきます。都市計画を学ぶ人、経営を学ぶ人、生物を学ぶ人。見えている課題がそれぞれ違います。後者は、手を動かして詰まって直した回数でしか身につきません。

だから OneThing が大事にしているのは、**エンジニアリングの精神 × 自分の専門**です。

情報系の知識を前提にしていません。作りたいものがある人と、作り方を知りたい人が同じ場所にいれば、それでいい。

## 今やっていること

### もくもく会（週1回程度）

各自が作りたいものを持ち寄って、黙々と手を動かす会。次回で49回目になります。

途中参加も途中退出もできます。会場は株式会社ゲームシストさん。時間は 18:30 から 21:00 が基本です。

「何を作るか決まっていない」状態で来ても大丈夫。周りが何をやっているかを見るだけでも、だいたい何か思いつきます。

### 勉強会

その時に知りたいことを、知っている人が話す形式でやっています。過去のトピックはこんな感じ。

- Claude Code の使い方
- git command
- Stripe を使った課金機能の実装
- OLTP と OLAP の違い（データベース設計の話）
- LLM エージェントシステム（社会工学類で研究しているメンバーを招いて）

最後のものが、この団体の性格をよく表しているかもしれません。**研究している本人が来て話す。** 教科書の内容をなぞる会ではありません。

### LT会

1人5分の持ち時間で、作ったものを話す会です。飛び入りの発表も歓迎しています。

うまくいった話だけを聞く場ではありません。**何に詰まったか、何を間違えたか**が、聞いている側にとっては一番役に立ちます。

### 協賛企業とのプロジェクト

企業と一緒に進めるプロジェクトもあります。手伝ってくれる人を随時探しています。

## 参加している人

だいたい5人から8人が集まります。大人数のサークルではありません。

学類の指定はありません。学年の指定もありません。1年生も来ます。

筑波大学の学生が中心ですが、つくば周辺で働いているエンジニアの方も参加しています。

## 来るときに必要なもの

**事前の入会手続きはいりません。参加費も無料。**

イベント一覧から気になる回を選んで、当日来てください。パソコンを持ってきてもらえれば、もくもく会はそれだけで参加できます。

初めてで不安なら、公式X のDM か公式LINE で聞いてください。当日の様子を先に伝えます。

「作りたいものはあるけど、作り方が分からない」。その状態のまま来てくれるのが、一番ありがたいです。
